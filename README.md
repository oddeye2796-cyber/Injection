# 플라스틱 사출 공정 MES 목업

플라스틱 사출 공장의 생산관리 시스템(MES) 화면을 클릭해 볼 수 있는 단일 HTML 목업입니다. 작업지시·작업배정부터 현장 사출작업일보(POP), 조립·선별 작업일보, HoldCard 관리, 비가동·불량 현황, 설비종합효율(OEE), 작업지시별 트렌드(USL/LSL), AI 품질 예측·공정 최적화, 출하, 기준정보(BOM·BOP·금형·설비)와 시스템 관리까지 다룹니다. 서버나 설치 없이 `index.html`을 브라우저로 열면 됩니다.

- 언어: 한국어 / English / 日本語 (상단 언어 버튼)
- 테마: 다크 / 라이트 (상단 테마 버튼)
- 로그인: 아이디·비밀번호 아무 값이나 입력하면 들어갑니다. 주소 끝에 `#auto`를 붙이면 로그인 화면을 건너뜁니다. 상단 **현장 POP** 버튼으로 설비 앞 현장 작업자용 사출작업일보 화면을 볼 수 있습니다.
- 데이터: 모든 데이터는 예시이며 브라우저(localStorage)에만 저장됩니다. 브라우저 사이트 데이터를 지우면 처음 상태로 돌아갑니다.
